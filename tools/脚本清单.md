# 脚本清单

> 更新时间：2026-08-09
> 适用工作区：`~/rong_ws/ws_offboard_control`

根目录脚本已按功能归入 `tools/`。每个脚本自解析工程根（`script_dir/../..`），
可从任意目录调用，无需先 `cd` 到工程根。

## 安全分类

执行前先确认类别。`FLIGHT` 类会解锁飞机或发布 setpoint。

| 类别 | 脚本 | 说明 |
| --- | --- | --- |
| `FLIGHT` | `tools/flight/一键启动导航栈.sh`<br>`tools/flight/一键启动起飞栈.sh`<br>`tools/flight/开机自启动起飞栈.sh`<br>`tools/flight/运行导航控制.sh` | 会启动硬件链并可能发布 setpoint，需现场看护 |
| `FLIGHT_CONFIG` | `tools/autostart/启用开机自启.sh`<br>`tools/autostart/禁用开机自启.sh` | 修改开机自启，影响下次登录行为 |
| `NONFLIGHT_HARDWARE` | `tools/rosbag/开始录包.sh`<br>`tools/rosbag/停止录包.sh`<br>`tools/flight/无桨视觉验证.sh` | 拆桨手持验证与录包，不发 setpoint |
| `OFFLINE` | `诊断.sh`<br>`tools/checks/*`<br>`tools/rosbag/查看最近录包.sh`<br>`tools/rosbag/刷新录包状态.sh`<br>`tools/analysis/*`<br>`tools/fastlio/校验杆臂配置.sh` | 只读检查与离线分析 |
| `OFFLINE_DESTRUCTIVE` | `tools/rosbag/删除历史录包.sh` | 删除历史 bag，不可恢复 |

## 目录分类

```
tools/flight/      起飞、悬停、一键栈、拆桨 EV 验证
tools/fastlio/     FAST-LIO 建图/重定位/地图存取、杆臂配置校验
tools/rosbag/      录包、停止、状态查询、清理、shutdown service
tools/checks/      启动前自检、地图与重定位状态、MAVROS 状态监控
tools/analysis/    无桨录包离线分析（MID360 轴向、EV 验证、twist 旋转校验）
tools/autostart/   开机自启的启用与禁用
```

## 主入口

一键栈是日常入口，按序拉起雷达驱动、FAST-LIO、MAVROS/EV 链、录包和控制节点：

```bash
MAP_FILE=/path/to/arena.pcd ./tools/flight/一键启动导航栈.sh
```

启动前自检（只读，建议先跑）：

```bash
./tools/checks/起飞前自检.sh
```

## 起不来的时候用诊断脚本

`诊断.sh` 只读：不发话题、不调服务、不改 PX4 参数、不解锁。它按依赖顺序分五层检查，
报告**最先坏的那一层** —— 坏层下游必然连带失败，逐个追那些症状正是上次把 FAST-LIO
延迟问题误判成坐标系问题的原因。

```bash
./诊断.sh                 # 静态 + 运行时全量
./诊断.sh --static        # 只查静态前提，不需要栈在跑
./诊断.sh --probe-sec 10  # 加长运行时采样窗口（默认 5s）
./诊断.sh --watch 5       # 每 5s 重复运行时层，Ctrl+C 退出
```

退出码：`0` 全通过，`1` 只有警告，`2` 至少一项失败。

## 速度坐标系校验

`tools/analysis/校验速度旋转.py` 逐样本核对
`vision_speed == R(child->world) * /Odometry.twist`，可在线也可查 bag：

```bash
PYTHONNOUSERSITE=1 python3 tools/analysis/校验速度旋转.py --seconds 30
PYTHONNOUSERSITE=1 python3 tools/analysis/校验速度旋转.py --bag <场次>/rosbag
```

退出码 `0`=PASS、`1`=INCONCLUSIVE、`2`=FAIL。**飞机近水平静止时它会判
INCONCLUSIVE 而不是 PASS**：那种姿态下 R 接近单位矩阵，"旋转正确"和"旋转缺失"
的输出无法区分，必须在物理转 90° yaw 的区间上跑才有结论。结果见
[速度坐标系取证.md](速度坐标系取证.md)。

杆臂配置校验（一键栈内部也会调用，失败即拒绝起飞）：

```bash
./tools/fastlio/校验杆臂配置.sh src/px4_ros_com/config/mid360_lever_arm.conf
```

## EV 链唯一路径

```
MID-360 -> FAST-LIO -> /Odometry -> fastlio_odometry_guard
  -> /Odometry/healthy -> fastlio_mavros_vision_bridge
  -> /mavros/vision_pose/pose_cov -> MAVROS -> PX4 EKF2
```

这是向 PX4 提供外部视觉定位的唯一通路。曾并存的
`fastlio_mavros_odometry_bridge`（`/mavros/odometry/out`）和
`fastlio_vehicle_visual_odometry`（`/fmu/in/vehicle_visual_odometry`）已删除：
它们默认关闭，但仅靠 launch 参数互斥，两个 launch 同时起就会出现多个 EV 写者。

新增或修改 PX4 EV 写者前，核对当前 launch/config、桥接实现和
`src/px4_ros_com/test/ev_entry_contract_static.py`；`坐标转换.md` 不再作为权威依据。
