# 飞手 OFFBOARD 触发的预设航点任务

任务入口：

```bash
RVIZ=false ./tools/flight/运行预设航点任务.sh
```

`RVIZ` 是显示开关，允许值为 `true` 或 `false`。当前应用航点默认位于
`src/race_offboard/config/waypoints/main/`，其中包含 `waypoints.yaml` 和
`mission.yaml`；历史采集会按日期保存在同级日期目录中。

## 配置

建图完成并将地图加载到 RViz 后，使用一键脚本记录飞机当前坐标：

```bash
MAP_FILE=/absolute/path/course.pcd \
./tools/flight/一键保存航点.sh
```

脚本启动 MID-360、FR-LIO、MAVROS、主地图加载、RViz 和一次全局重定位，且固定关闭任务与控制输出。重定位完成后才允许保存。可在飞行手动控制中将飞机飞到目标点，也可不飞、手持设备到目标位置后按一次回车；前四个点自动命名为 B1、B2、C、D，后续点命名为 P005、P006……每个点会采集稳定的 `/race/odom`，检查 `frame_id=map`、时间戳和位置抖动，然后写入本次日期目录。完成 B1/B2/C/D 后，本次采集会成为新的 `waypoints/main` 当前应用；原来的 `main` 会先保留到日期目录，不会丢失。保存模式不要求 `/ev_health/flight_ready=true`。本次采集内允许更新同名航点；脚本不会覆盖历史日期目录。脚本不会自行停止，按 `Ctrl-C` 后会逆序清理本次启动的全部组件。

保存航点脚本会同步把 `waypoints.yaml` 发布到 `/race/saved_waypoints`，RViz 会自动显示青色圆点、航点名称和橙色保存顺序连线。每次保存成功后约一秒刷新一次；该显示仅用于核对坐标，不会发布飞行控制指令。

## 仅全局规划验证

不连接 PX4/MAVROS 和控制节点，仅加载地图、定位和 Super 全局规划器时，运行：

```bash
./tools/flight/运行全局航点规划.sh
```

它按 `mission.yaml` 中的 B1、B2、C、D 顺序向 `/goal_pose` 请求全局路径，并发布 `/race/global_path` 供 RViz 显示。节点依据 `/race/odom` 到点半径推进；到达 B1 和 D 时分别在 `/race/global_waypoint_task/state` 发布 `B1`、`D`，且终端打印状态切换成功。默认 `PX4_COMPONENTS_ENABLED=false`。只有在确实需要恢复 PX4/MAVROS 和 Offboard 控制链时，才显式设置 `PX4_COMPONENTS_ENABLED=true`；该开关不等于允许飞行，控制输出仍固定关闭。

在任务文件填写统一 `map` 坐标系的 ENU 平面点，必须刚好四个，顺序为 B1、B2、C、D：

```yaml
preset_points:
  - [b1_x, b1_y]
  - [b2_x, b2_y]
  - [c_x, c_y]
  - [d_x, d_y]
```

同时按场地需要调整 `arrive_radius`、`b2_hold_sec` 和 `d_hold_sec`。不要填入未做坐标对齐和障碍物校核的坐标。

## 从保存航点生成任务

也可以分步执行保存和导出：

```bash
./tools/flight/保存航点.sh B1 xy 0.78 /absolute/path/course.pcd
./tools/flight/保存航点.sh B2 xy 0.78 /absolute/path/course.pcd
./tools/flight/保存航点.sh C  xy 0.78 /absolute/path/course.pcd
./tools/flight/保存航点.sh D  xy 0.78 /absolute/path/course.pcd
./tools/flight/生成预设航点任务.sh /absolute/path/course_mission.yaml
```

最后一条命令只在四点完整、坐标有限、记录的 frame 为 `map` 时才会原子写入任务 YAML。它生成的 `preset_points` 顺序固定为 B1、B2、C、D，并携带来源地图 SHA256 供追溯。使用生成文件启动：

```bash
MISSION_FILE=/absolute/path/course_mission.yaml \
RVIZ=false ./tools/flight/运行预设航点任务.sh
```

## 执行边界

脚本只启动导航栈，不会解锁、起飞或请求 OFFBOARD。飞手手动起飞并稳定到配置巡航高度后，切换 PX4 至 `OFFBOARD`。`mission_sequencer_node` 仅在 `/mavros/state` 报告 `mode=OFFBOARD` 的上升沿发布 B1；随后按 B1 -> B2（停留）-> C -> D（停留）推进。

切离 OFFBOARD 会暂停任务。现有控制节点把这视为飞手接管并锁存，因此不得依靠再次切入 OFFBOARD 恢复同一次任务；重新启动任务入口后再执行新的飞行事务。

`mission_sequencer_node` 只发布 `/goal_pose`。规划、轨迹校验和 `/mavros/setpoint_raw/local` 的唯一发布权仍属于原有节点。
