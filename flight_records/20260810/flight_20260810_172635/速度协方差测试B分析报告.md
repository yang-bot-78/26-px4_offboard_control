# FAST-LIO 速度协方差测试 B 分析报告（仅水平）

## 结论

本场前后、左右各完成 5 次往返，方向、位移、时间戳、速度符号均正确。FAST-LIO 与 PX4 本地水平速度高度一致，X/Y 相关系数分别为 `0.9976/0.9971`，水平误差 p95 为 `0.0453 m/s`，没有可测出的额外固定时延。

测试 B 的水平部分通过，但当前约 `0.00015 m2/s2` 的原始速度方差在运动中偏小。按 2.0 倍安全系数，建议采用以下**世界 ENU 水平协方差下限**：

```text
X: 0.0016 m2/s2  (sigma = 0.040 m/s)
Y: 0.0013 m2/s2  (sigma = 0.036 m/s)
```

本场按要求没有垂直移动数据。PX4 的 `EKF2_EV_CTRL` bit 2 是三维速度融合，不支持只打开水平速度。因此当前必须继续保持 `EKF2_EV_CTRL=11`，不能根据本报告改成 15。

```text
TEST_B_HORIZONTAL = PASS
FASTLIO_HORIZONTAL_VELOCITY_VALID = YES_FOR_SHADOW_AND_COVARIANCE
HORIZONTAL_COVARIANCE_READY = PROVISIONAL_PASS
VERTICAL_COVARIANCE_READY = NO_DATA
READY_TO_CHANGE_EKF2_EV_CTRL = NO
READY_FOR_EV_VELOCITY_FUSION = NO
REQUIRED_EKF2_EV_CTRL = 11
```

## 协方差判断

当前动态误差落在“声明的两倍标准差”内的比例只有：

```text
X: 83.5%
Y: 85.7%
```

理想高斯数据的参考比例约为 95.4%，所以当前原始协方差虽然能覆盖测试 A 的静止噪声，却不能充分覆盖本场动态误差。

按操作文档公式：

```text
sigma = 2.0 * max(RMSE, p95(abs(error))/1.96, 测试A静止标准差)
variance = sigma^2
```

得到：

| 轴 | 计算 sigma | 计算方差 | 建议取整后的下限 |
| --- | ---: | ---: | ---: |
| X | 0.03922 m/s | 0.001538 m2/s2 | **0.0016 m2/s2** |
| Y | 0.03472 m/s | 0.001206 m2/s2 | **0.0013 m2/s2** |

这两个值是源消息的水平下限，应该在完整 3x3 协方差旋转到世界 ENU 后施加，并保持矩阵对称、半正定。不能在 bridge 末端清零整个矩阵后只写两个对角元素。

### PX4 参数对源协方差的影响

本场没有捕获实际 PX4 参数值。当前 PX4 源码定义：

```text
EKF2_EV_NOISE_MD=0 时：有效方差 = max(消息方差, EKF2_EVV_NOISE^2)
EKF2_EV_NOISE_MD=1 时：忽略消息方差，直接使用 EKF2_EVV_NOISE^2
EKF2_EVV_NOISE 默认值：0.1 m/s，即 0.01 m2/s2
```

如果飞控仍是默认 `EKF2_EVV_NOISE=0.1`，PX4 实际采用的下限 `0.01 m2/s2` 会大于本报告建议的 `0.0016/0.0013`。修改源协方差后不要立即降低 PX4 噪声参数；先在 QGC 中只读确认实际的 `EKF2_EV_NOISE_MD`、`EKF2_EVV_NOISE` 和 `EKF2_EVV_GATE`。

## 适用范围与下一步

本测试证明了水平平移时的符号、坐标旋转、频率、时序和相对速度一致性。它不是独立真值测试：PX4 本地速度本身是 EKF 输出，并且本场处于未解锁地面状态。因此建议值是保守的工程下限，仍需飞行 shadow 数据复核。

后续顺序：

1. 在 health monitor 的世界 ENU 速度协方差中加入 X/Y 下限 `0.0016/0.0013 m2/s2`，Z 不根据本场修改。
2. 保持 `EKF2_EV_CTRL=11`，重新录制 POSITION 悬停和小幅水平移动的 shadow 数据。
3. 在 QGC 只读确认 `EKF2_EV_NOISE_MD`、`EKF2_EVV_NOISE`、`EKF2_EVV_GATE`，不要同时修改多个参数。
4. 如果决定永久不做垂直速度验证，则保持 EV velocity 关闭；这不妨碍继续使用已经验证的位置、高度和 yaw 融合进行 POSITION/位置型 Offboard。
5. 若以后需要启用 EV velocity，必须补充垂直证据并在拆桨地面阶段先验证 `cs_ev_vel`、三轴 innovation、test ratio 和 rejection，再进入低高度飞行。

原始机器可读统计位于同目录 `速度协方差测试B分析数据.json`，可复跑脚本为 `tools/analysis/分析速度协方差测试B.py`。
