## 当前协方差是否可信

当前 vision_speed 的声明标准差约为 0.012–0.013 m/s。测试 A 的实测标准差约为：

```text
X 0.0080 m/s
Y 0.0092 m/s
Z 0.0045 m/s
```

各静止段约 98.6%–100% 的样本落在声明的两倍标准差范围内。三维归一化误差（NIS）平均约 1.0–1.4，低于三维理想均值 3；95% 分位约 3.3–3.9，也低于卡方 95% 阈值 7.815。

因此：

```text
STATIC_COVARIANCE_OPTIMISTIC = NO
STATIC_COVARIANCE_CONSERVATIVE = YES
STATIC_NOISE_TEST = PASS
```

当前约 `0.00015 m2/s2` 的 FAST-LIO 原始速度方差对静止噪声是略保守的，不应仅根据测试 A 将其直接放大到 `0.01/0.01/0.04 m2/s2`。

## 本阶段结论

测试 A 证明：

1. 静止时 FAST-LIO 速度零偏很小；
2. 当前原始协方差能够覆盖静止随机噪声；
3. yaw 和轻微倾斜姿态没有导致坐标旋转错误；
4. 10 Hz 输出在本场次连续且低延迟；
5. EV 健康监视全程稳定。

测试 A 不能证明：

1. 加速、减速和匀速移动时的动态模型误差；
2. 垂直运动中的速度延迟；
3. 杆臂和机体转动带来的动态速度误差；
4. 开启 PX4 EV velocity 后的 innovation 和拒绝情况。

因此当前状态为：

```text
TEST_A_STATIC = PASS
READY_FOR_TEST_B_DYNAMIC = YES
READY_TO_CHANGE_EKF2_EV_CTRL = NO
READY_FOR_EV_VELOCITY_FUSION = NO
```
